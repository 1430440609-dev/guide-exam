# 导游刷题

导游资格考试科目三、科目四个人练习网站。判断题、单选题选择后，正确答案和解析直接出现在选项下方；多选题点击提交后显示。答题前不显示答案。

## 手机点击切题与重复练习

选项上方提供「快速上一题」「快速下一题」两个小按钮，底部按钮也可使用。多选题未提交的选择会保留，不会自动提交或提前显示答案。

切换练习方式或筛选会开始新一轮，历史答案不会直接显示；作答后才显示本轮答案和解析。刷新或重新打开网站会恢复当前轮次、题号、随机顺序和未提交的多选选择。再次点击当前练习标签不会重置进度。

「重新刷本套题目」从当前题组第一题开始，隐藏本轮答案、清空本轮作答与草稿；历史错题、收藏、最近作答和完成遍数保留。即使本轮错题已答对并移出错题清单，重刷仍使用同一题组。页面显示正在刷第几遍与已完整刷完几遍；只有全部作答才计为完整一遍，刷新、重练单题和中途重刷不会重复计数。不同练习方式和筛选条件分别计数，遍数从此功能上线开始累计。

## 一起使用

公开网址提供相同题库。每个人的答题记录、错题和收藏保存在各自的浏览器中，互不影响。无需注册，不提供跨设备进度同步。清除浏览器数据会清除该浏览器的练习记录。

## 后续加题

新题由维护者统一整理并追加到共享题库。刷新原网址即可读取更新，无需更换网址。追加题目时保留既有题目 ID、题干和顺序，以及本地保存记录的存储键。网站使用相对路径，兼容 GitHub Pages 项目网址。

本仓库仅包含发布所需的网站文件及结构化题库，不包含用户原始文档、个人答题记录或账号凭证。

## 发布

GitHub Pages 从 `main` 分支根目录发布。静态资源直接部署，无需安装依赖或运行构建。保留 `.nojekyll` 文件。
