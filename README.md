# 导游刷题

导游资格考试科目一至科目四个人练习网站。判断题、单选题选择后，正确答案和解析直接出现在选项下方；多选题点击提交后显示。答题前不显示答案。

## 手机点击切题与重复练习

手机和电脑均只保留屏幕底部固定的上一题、下一题操作栏；题目区域不再重复显示切题按钮。多选题未提交的选择会保留，不会自动提交或提前显示答案。

从十二套完整试卷中选择一套练习，每套165题；顺序练习严格按文档原题号排列，不按科目或题型拆分。随机练习按原题型区间分别打乱：前40题仍为判断题，中间90题仍为单选题，最后35题仍为多选题。判断题“对/错”选项顺序固定；仅单选和多选选项打乱。判分始终使用原选项身份和原文答案；作答后显示本页答案、原文参考答案与字母对应关系，原文解析保持不变。

每套试卷的顺序、随机、错题和收藏练习分别保存进度。切换模式保持所选试卷；切换试卷或重新打开网站会恢复对应题号、轮次、已答状态、草稿以及随机题序和选项排列。首次练习不会直接显示历史答案。

「重新刷本套题目」才开始新一遍。

「重新刷本套题目」从当前题组第一题开始，隐藏本轮答案、清空本轮作答与草稿；历史错题、收藏、最近作答和完成遍数保留。顺序或随机练习中新答错的题会自动加入错题清单，普通练习答对不会直接移除已有错题。错题练习在本轮全部作答后统一移除答对题，并保留最后一题的答案与解析供回顾；剩余错题通过“继续练剩余错题”重新作答。重新进入或刷新也只加载剩余错题，不重复显示已经移除的题。新产生的错误不会被更早的答对记录误清除。页面显示正在刷第几遍与已完整刷完几遍；只有全部作答才计为完整一遍，刷新、重练单题和中途重刷不会重复计数。不同试卷和练习方式分别计数，遍数从此功能上线开始累计。

## 一起使用

## 巩固、模拟考试与备份

手机底部常驻上一题、待巩固、收藏和下一题按钮；多选未提交时，主按钮为提交答案。切题会回到新题题干。试卷学习进度面板可展开查看各套已刷遍数、本轮进度、错题、待巩固、今日到期数和最近模拟考试分数，一键继续对应试卷。

答对但不确定的题可手动标记为待巩固，并加入到期复习。答错的题安排次日复习；正确巩固后按1、3、7天间隔递进，再次答错则从次日重新开始。到期提醒显示在页面内，不发送系统通知。取消待巩固标记不会删除已有复习安排。

模拟考试独立保存每套试卷的本场作答，完整165题。所有题型在交卷前均可修改作答，选项、答题卡和题目区域均不显示对错、答案或解析。交卷后锁定作答、统一显示分数和分题型报告，并可逐题查看原文答案解析。未答和答错的题加入错题。计分：判断40题×0.5分=20分；单选90题×0.5分=45分；多选35题×1分=35分，总分100分。多选只有全部选对才得1分，漏选、错选、未答均得0分。评分只依据原题标准答案，不依据历史正确标记。交卷后可重新开始下一场，未交卷考试切换模式或重新打开仍可继续。

「备份与恢复」可下载JSON进度文件，包含错题、收藏、待巩固、复习安排、轮次、独立模式进度、未提交选择及未交卷考试。换手机可手动导入该文件；选择后先显示校验摘要，点击恢复才替换本机进度。恢复不会导入题库或改写标准答案，并会重新核对作答正确性。

## 个人进度

公开网址提供相同题库。每个人的答题记录、错题和收藏保存在各自的浏览器中，互不影响。无需注册，不提供跨设备进度同步。清除浏览器数据会清除该浏览器的练习记录。

## 后续加题

新题由维护者统一整理并追加到共享题库。刷新原网址即可读取更新，无需更换网址。追加题目时保留既有题目 ID、题干和顺序，以及本地保存记录的存储键。网站使用相对路径，兼容 GitHub Pages 项目网址。

本仓库仅包含发布所需的网站文件及结构化题库，不包含用户原始文档、个人答题记录或账号凭证。

## 发布

GitHub Pages 从 `main` 分支根目录发布。静态资源直接部署，无需安装依赖或运行构建。保留 `.nojekyll` 文件。

## 当前题库

共 12 套试卷、1980 题（判断 480、单选 1080、多选 420）。每套 165 题，分别是考前押题 01–06 的科一科二卷和科三科四卷。24 份题目/解析文档按卷号、科目、题号、题干及选项配对；每题参考答案取自配套文档的明确答案字段。原有第 03 套科三科四不重复添加，原有题号和答题记录关联保留。每套仍按其文档顺序，原文在不同试卷中重复出现的题目保留在各自试卷中，作答记录分别保存。

本次新增第 05、06 辑四套卷，共660题。题目与解析版的字形差异按来源记录核对，答案不作推断性修改。一道题原解析缺少单独科目标签，按其文档卷名保留“科三科四”标签，不影响题目顺序和评分。

## 全题库随机模拟与计时

模拟考试中的“考试方式”可选择当前整套试卷或本组题库随机组卷。随机卷从所选科一科二或科三科四组的990条原文题目中，按科目及章节比例抽取40判断、90单选、35多选，题型区间固定，总分100；同文档及跨文档的源题ID均分别保留，不做内容去重。抽题只变动题序，原选项、标准答案和计分不变。

各题型先按原科目和章节比例分配，再优先未刷题，约20%名额穿插当前轮次的错题；没有足够错题时补未刷题，没有足够未刷题时补错题。正式交卷后，答对题从本轮可抽池排除，答错题继续可抽；未答不计入覆盖，仍可抽。累计已刷/剩余未刷按当前组唯一源题ID统计，重复作答不重复增加；待巩固显示随机模拟中最近一次交卷答错的题。整套模拟和日常练习不改变该独立随机模拟统计。

题型或科目配额剩余量不足时明确显示缺口，不会暗中重复已答对题或生成不足165题的试卷。交卷后可明确点击“开始新一轮”，本轮排除记录重置，累计覆盖及历史成绩保留；之后仍按相同规则。新加入题库会进入可抽池，不改变正在作答的已组试卷。

整套及随机模拟均按实际当前页面的考试时间计时：页面隐藏、切换模式、退出暂停，恢复后接续；交卷锁定用时。交卷报告显示分数、分题型正确率、用时；随机卷还显示本次新增刷题数与累计覆盖。随机模拟保留逐场成绩、用时、题序和作答，页面列最近10场，全部记录随备份导出。交卷后的“练习本次错题”包含本场答错与未答题，重新作答后才显示解析，全部完成后按既有错题规则统一移除答对题。所有原练习模式的位置与记录继续独立保存。

## 分组开始模拟考试与内容均衡

进入模拟考试后先选择“科一科二模拟考试”或“科三科四模拟考试”，点击后才显示题目和计时；重新进入也由对应按钮继续原卷。未点击时不创建考试、不计时、不显示题目或答案。两组各6套文档、990题，随机卷只从当前组抽题；组内可切换整套文档模拟，纸卷选择和考试方式也分别记住。

随机组卷在判断40、单选90、多选35的固定区间内，按原文档的科目比例及原章节标注均衡抽题。科一科二判断20/20、单选46/44、多选17/18；科三科四按源资料比例做整数分配，缺少单独科目标注的题保留原标签。“本卷考核分布”可以展开核对实际科目和章节题量。只有最后一道题才出现“交卷并评分”；前面的题目只提供下一题。

两组的随机覆盖、答对排除、错题复考、轮次、成绩与用时分别保存。原先混合随机模拟的已交卷覆盖按原科目迁移到两组；原历史和未完成混合卷保留在进度备份中，新的分组模拟不会继续使用混合卷。剩余题量若无法满足原科目比例，会提示具体缺口，并由用户选择开始新一轮。答案、选项身份和100分计分方式不变。

## 退出后查看考试错题

模拟考试首页提供科一科二、科三科四的“考试错题”按钮，直接练本组仍待巩固的考试错题与未答题，无需开始新考试。下方“考试记录与错题”保留每场成绩、用时和“重练本场错题”入口；最近10场默认显示，可继续加载更早记录。历史错题即使已练对，仍能从该场记录重新作答，答前不显示解析。退出后重新打开同一浏览器仍可查看，重练中途退出也可继续。整套卷和随机卷历史均保存，开始新考试不会覆盖已保存历史。旧版本已有的随机历史、最近整套考试成绩和已交卷快照自动显示。所有新历史随进度备份导出与校验恢复。

## 历史成绩总结

模拟考试首页的“历史成绩与错题”汇总本浏览器已保存场次、最近分数和最高分。每场可展开“查看成绩总结”，查看总分、判断/单选/多选得分及正确率、作答情况和考试用时，无需开始新的考试。加载时自动归档可恢复的旧随机考试记录、最近整套考试及已交卷快照，已有成绩不重复计数，并随备份保存。没有保留作答记录的早期成绩无法推算，不生成虚构历史成绩。

## 先看考试错题，再重做

考试错题入口现在先显示当场作答、正确答案与原文解析，可用底部按钮逐题回顾。点击“重做错题”才隐藏答案，从本组第一题重新答题。回顾不改变原分数、错题状态或完成遍数；重做仍按全部作答后统一移除答对题的规则处理。回顾与重做阶段、题号及选择均可在退出后恢复，历史考试记录保持原样。

## 模拟考试与错题重做的选项乱序

模拟考试作答时，单选和多选选项会打乱，判断题对/错顺序不变。切题、刷新或恢复备份保留本场选项顺序与选择。交卷后查看答案、打开考试错题回顾、以及重做题提交后，选项恢复原文顺序，答案字母与原文解析保持一致。再次点击“重做错题”或重练本题时生成新的选项排列；保存与判分始终使用原选项身份，不会因字母变化而错判。
